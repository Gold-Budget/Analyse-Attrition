# Analyse-Attrition
Le projet suivant fait office d'analyse de rétention (ou "churn") afin de représenter, en usant de statistiques, le visage du client typique susceptible de se désabonner d'un service de streaming fictif sur lequel des films et des séries sont disponibles, l'utilisateur ayant en outre la possibilité de choisir son type d'abonnement. 
Cet ensemble de données a été créé dans le cadre d'un projet de science des données. Les informations présentes y sont fictives. 
Cet ensemble de données contient des informations sur les clients susceptibles de se désabonner (« 1 ») ou non (« 0 »).
Après plusieurs tests (corrélation, Chi², matrice), il s'est avéré que le client typique susceptible de churn avait les caractéristiques suivantes : inscrit à un abonnement basique, fan de films de science-fiction et/ou d'action, et doté d'un abonnement lui permettant de regarder du contenu sur plusieurs appareils.
